Netlify build settings (already in netlify.toml):

Supabase config:
The browser URL and publishable key are included as public client values in src/lib/supabaseClient.js. They are not service-role credentials. Never add a service-role or secret key to this project.

Admin:
Visit /admin and sign in using the existing Supabase Auth account already authorised in public.admin_users. The dashboard checks the public.is_admin() function before exposing data or editing actions. If login succeeds but administrator access is denied, inspect the existing admin_users row and is_admin() function in Supabase; do not disable RLS or expose a service-role key. The frontend cannot recover the account password.
